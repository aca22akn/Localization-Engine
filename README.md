# UK Market Localization Engine

Analyses Pakistani fashion brand websites and scores them across 9 trust dimensions for UK customers.

## Setup

**1. Install dependencies**
```
npm install
```

**2. Create a `.env` file** in this directory with your Anthropic API key:
```
ANTHROPIC_API_KEY=your_api_key_here
```

**3. Start the server**
```
node server.js
```

The server runs on `http://localhost:3001`. Open `index.html` in your browser to use the tool.
